# 打熊与医院原始画面采集指南

本指南用于收集高级打熊卡片识别和医院治疗流程所需的真实画面证据。当前实现状态与剩余开发事项以[恢复计划](bear-rally-hospital-recovery-plan.md)为准。

## 1. 首批最小素材

暂时只需优先提供以下四张图片：

1. 打熊联盟集结列表；
2. 野外快捷医院图标可见的 WORLD 页面；
3. 点击野外快捷医院图标后进入的治疗页面；
4. 治疗开始并请求联盟帮助后的页面。

拿到首批素材后，先确认页面结构、字段含义和模板稳定性，再按实际缺口补充灰色按钮、空列表、零伤兵等负例。不要提前批量收集所有异常状态。

## 2. 通用要求

- 图片必须是未经缩放的原始 PNG，目标分辨率为 `720x1280`。
- 优先使用模拟器自带截图或 ADB 截图，不要使用手机拍屏、系统区域截图或聊天软件转发后的图片。
- 保留完整游戏画面，不得裁剪、旋转、拼接或改变 DPI。
- 截图前等待页面动画结束，关闭无关菜单、键盘和悬浮窗口。
- 每组素材注明游戏界面语言、模拟器名称、实际分辨率、DPI、昼夜/雪景效果状态和截图前操作。
- 如果实际分辨率不是 `720x1280`，保留原图并说明尺寸，不要自行缩放。

可使用以下 ADB 命令截图；存在多个设备时加入 `-s <设备编号>`：

```powershell
adb exec-out screencap -p > screenshot.png
adb -s <设备编号> exec-out screencap -p > screenshot.png
```

## 3. 打熊集结列表

进入联盟打熊活动的集结列表，等待列表稳定后截图。

画面最好同时包含两个以上可加入卡片，并完整显示：

- 发起人名称；
- 当前成员数和最大成员数；
- 当前兵量；
- 集结总容量；
- 剩余可加入容量；
- 倒计时；
- Join/加入按钮；
- 卡片完整上下边界。

同时说明每组数值的实际含义。若列表中存在灰色或不可加入卡片，再额外提供一张，但不要为了制造负例执行危险操作。

建议文件名：

```text
bear_rally_list_joinable_zh.png
bear_rally_list_disabled_zh.png
```

## 4. 野外医院入口

当伤兵达到快捷医院图标出现条件时，停留在完整 WORLD 页面并截图。图标必须清楚可见，且不能被聊天框、活动窗口或其他悬浮元素遮挡。

截图后点击该图标，等待页面转换和动画完全结束，再采集治疗页面。请说明点击后是否直接进入治疗页面，还是先出现中间菜单。

建议文件名：

```text
hospital_field_world_zh.png
hospital_field_opened_zh.png
```

## 5. 治疗页面

治疗页面需要完整显示：

- 页面标题或其他可证明当前页面身份的元素；
- 伤兵总数；
- 兵种或兵阶区域；
- 数量输入框；
- 治疗按钮；
- 治疗所需时间；
- 联盟帮助、取消或加速入口（若当前可见）。

如果未输入数量时治疗按钮为灰色，先截一张灰色状态；再手动输入 `1`，确认按钮状态变化后截一张。只进行小批量操作，避免为取证消耗大量资源。

建议文件名：

```text
hospital_empty_input_zh.png
hospital_input_one_zh.png
```

## 6. 治疗进行中与联盟帮助

手动开始一次小批量治疗并请求联盟帮助，等待状态刷新后截图。画面至少保留以下一种正证据：

- 联盟帮助状态或帮助次数；
- 治疗剩余倒计时；
- 治疗进行中标识；
- 取消或加速入口。

同时记录本次治疗数量、开始前显示的治疗时间、是否成功请求帮助，以及截图时看到的剩余时间。

建议文件名：

```text
hospital_healing_help_requested_zh.png
```

## 7. 后续城内医院素材

首批素材确认后，再根据需要提供：

1. 城内医院建筑清楚可见的完整 HOME 页面；
2. 点击建筑后出现的建筑菜单（如果存在）；
3. 页面动画结束后的完整治疗页面。

建议文件名：

```text
hospital_city_home_zh.png
hospital_city_menu_zh.png
hospital_city_opened_zh.png
```

## 8. 隐私处理

可以脱敏玩家名、联盟名、头像和聊天内容，但必须遵守以下边界：

- 使用纯色块局部覆盖，不要模糊整张图片；
- 不得遮挡按钮边缘、卡片边界、图标或页面状态标识；
- 不得遮挡成员数、兵量、容量、倒计时、伤兵数、治疗时间和帮助状态；
- 同一流程中的同一玩家使用一致的代称，例如“玩家A”；
- 图片文件名不得包含真实姓名、QQ号、手机号、邮箱或游戏账号。

如果无法判断某处能否遮挡，优先保留原始文件本地不发送，另复制一份进行最小范围脱敏。

## 9. 提交前自检

- [ ] 图片是原始 PNG，未经过聊天软件压缩。
- [ ] 图片保持完整画面和原始尺寸。
- [ ] 已注明中文或英文界面。
- [ ] 已注明模拟器、分辨率、DPI 和画面效果。
- [ ] 已说明截图前操作和按钮可用状态。
- [ ] 关键数值、按钮和页面边界没有被遮挡。
- [ ] 文件名不包含个人隐私。
- [ ] 同一操作流程的图片顺序清楚。

这些素材只用于建立 ROI、模板、OCR 和页面转换证据。在保存帧测试和实机日志验证完成前，不据此直接宣称高级打熊或医院自动治疗可用。
